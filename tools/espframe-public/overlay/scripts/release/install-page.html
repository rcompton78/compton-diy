  1. Use Chrome or Edge on a desktop computer.
  2. Plug a USB-C data cable into the frame's bottom USB-C port (labelled USB).
  3. Click Install, pick the frame's serial port and confirm. It takes a few minutes.
  4. Enter your Wi-Fi when asked. If you aren't asked, join the immich-frame-10inch hotspot from a phone and set Wi-Fi there.
  5. Open the IP address shown on the frame in a browser and enter your Immich server URL and API key.
Your browser can't flash over USB. Use Chrome or Edge on a desktop computer. Flashing needs a secure (https) page.

A frame installed from this page checks this site's manifest.json for updates, so it only installs releases from this repository.
