  1. Use Chrome or Edge on a desktop computer.
  2. Plug a USB-C data cable into the frame's bottom USB-C port (labelled USB).
  3. Click the Install button for your board (see below), pick the frame's serial port and confirm. It takes a few minutes.
  4. When it's done, the frame starts a Wi-Fi hotspot called immich-frame-10inch (immich-frame-10inch-v3 with the v3 chip build). Join it from a phone and pick your Wi-Fi network.
  5. Open the IP address shown on the frame in a browser and enter your Immich server URL and API key.

Which button?

The board ships with two revisions of its ESP32-P4 chip, and one firmware can't run on both. Boards bought from late 2026 onwards have a v3.1 or later chip: pick the v3 chip button if you're not sure and your board is new. Earlier boards take the other one.

If the screen stays black or the board keeps rebooting after installing one, install the other. Nothing is lost by trying the wrong one first. A v3.0 chip isn't supported by either build.
